Annotation test console // HAProxy Ingress

Each module fires a crafted request through your ingress and judges the response. Apply one annotation at a time on your Ingress (or the Service, for Gateway API), redeploy, then re-run the matching module.

Point target at the host that routes to this app. Leave it blank to use this page's own origin. Expand show annotation on any module to copy the exact YAML to apply.

Backend endpoints: /api/ping /api/delay?ms= /api/echo /api/headers /api/whoami /api/status?code= /api/size?bytes= /api/auth. Timeouts that need a slow client (timeout-client / timeout-connect) and large-header buffer tests are easier from scripts/test.sh — see the README.
